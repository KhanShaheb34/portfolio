# Portfolio structure grid

The portfolio grid structure should look something like this:

```
Intro   | Assorted Projects | Posts     | Academic  |
        |                   |           |           |
------  |                   | --------- |           |
        | ----------------- |           | --------- |
Links   |                   | Interests |           |
        | Open Source       |           | Hobbies   |
        |                   |           |           |
```

The whole page should be side scrollable, and the scroll bar won't be visible.

Here `-` should be squiggly lines and `|` should be vertical lines.

Each vertical section should be scrollable, but the scroll bar won't be visible.

Scrolling one vertical section will scroll only that section, and not the whole page.

At a time a regular size desktop screen will show 2.5 sections at most, and 3.5 sections if the display is too large, so that user can understand the page is side scrollable.

On the mobile devices, everything will stack vertically, and the whole page can be scrolled vertically.
